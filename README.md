# autodj
Emissora online de rádio e tv 

🎵 Reprodução automática de músicas
🎙️ Vinheta a cada 3 músicas
⏰ Programação diferente por dia da semana e horário
🔄 Quando terminar uma música, entra a próxima automaticamente
📻 Saída em MP3 128 kbps
🚀 FFmpeg como motor de transmissão
📡 Conexão com o SHOUTcast/SRVSH
📝 Registro do que foi executado
🔁 Se uma playlist acabar, iniciar novamente
🛑 Tratamento de arquivo inexistente/erro de reprodução
📊 Preparação para futuramente mostrar "tocando agora"
